# Exporters (Planned)

Export is a first-class product feature. Phase 10 will deliver:

- `EffectForgeExporter` abstraction in `@effectforge/exporter-core`
- React + Vite, Next.js, and Vanilla JS exporters
- `@effectforge/runtime` — small, framework-independent runtime package
- CI validation that exported projects install, compile, and build

Generated projects will include readable code, required third-party notices, and no editor dependencies.
