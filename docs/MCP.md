# MCP Server (Planned)

Phase 20 will deliver an MCP server using `@modelcontextprotocol/server` with stdio transport.

## Design

- Tools delegate to EffectForge core/commands — no DOM manipulation
- Path security with workspace root containment
- `render_preview` for AI agent visual inspection loops
- Resources for schemas, presets, and current project state

See the master specification section 58–61 for the full tool list.
